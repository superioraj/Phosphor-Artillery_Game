    01. 목표

    마지막까지 살아남으면 라운드 승리. 먼저 3승하면 경기 승리입니다.

    02. 한 차례의 흐름

    1. 이동 - A/D를 누르고 있으면 연료를 쓰며 이동
    2. 조준 - 각도와 위력 조절
    3. 포탄 선택 - 숫자 1~4
    4. 발사 - SPACE. 발사하면 차례 종료

    03. 조작 키

    키동작
    A D누르는 동안 왼쪽 / 오른쪽 이동
    ← →각도 ±1° (SHIFT: ±5°)
    ↑ ↓위력 ±10 (SHIFT: ±50)
    1~4포탄 선택
    SPACE발사
    ENTER전투 시작 / 다음 라운드
    F1 F2도움말 / 메뉴

    터치 화면: 이동 버튼을 길게 누르면 계속 이동합니다.

    04. 포탄

    포탄특징지급
    1 기본탄반경 26 / 피해 55무제한
    2 중포탄반경 45 / 피해 80라운드 1발 (최대 4)
    3 분열탄최고점에서 3갈래 / 반경 21 / 각 36라운드 1발 (최대 4)
    4 지진탄반경 67 구덩이 / 피해 24 / 추락 유도보급만 (최대 3)

    폭발은 둥근 구덩이를 만들고, 위쪽 흙은 아래로 내려앉습니다. 구덩이에 빠져도 벽을 타고 빠져나올 수 있지만, 아주 높은 절벽은 오를 수 없습니다.

    05. 전장 규칙

    • 이동 연료: 매 차례 48 (연료 2배 시 96)
    • 바람은 매 차례 조금씩 변함
    • 발밑 지형이 파이면 추락 피해
    • 30발 이후 모든 피해 2배 (서든데스)
    • 60발 도달 시 무승부
    • 포구 앞 점선 = 초반 탄도 가이드

    06. micro:bit 제어

    micro:bit동작
    오른쪽 / 왼쪽 기울기각도 높아짐 / 낮아짐
    위 / 아래 기울기위력 증가 / 감소
    A 버튼 누르고 있기왼쪽 이동
    B 버튼 누르고 있기오른쪽 이동

    로고 터치다음 라운드 / 새 경기

    08. AI 난이도 1~10

    • 1~2 조준 오차 큼, 바람 거의 무시
    • 3~4 바람 일부 계산, 보급 상자를 노려 이동
    • 5~7 고지대 이동, 함정 회피, 약한 전차 우선
    • 8~10 정확한 바람 계산, 특수탄 적극 사용

    09. 온라인 1:1

    1. 두 사람 모두 온라인 1:1 선택
    2. HOST: [방 만들기] → 5자리 방 코드를 상대에게 알려주기
    3. GUEST: [방 참가] → 방 코드 입력 → [접속]
    4. HOST: 접속 요청이 오면 [허용] → 자동 시작

    두 사람 모두 같은 v3.5 파일을 사용해야 합니다. 연결 시작에 무료 공개 중계 서버(PeerJS)를 사용하므로 인터넷이 필요하며, 서버 상태나 학교·회사 방화벽에 따라 연결되지 않을 수 있습니다.
